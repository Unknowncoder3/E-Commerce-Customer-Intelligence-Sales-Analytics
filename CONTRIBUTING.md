# Contributing

Thanks for taking an interest in the project.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Keep analytical changes reproducible.
4. Document meaningful transformations or assumptions.
5. Validate Python files before opening a pull request.

## Analytics standards

- Do not silently change source data.
- Document derived metrics and business definitions.
- Avoid unsupported business conclusions.
- Keep notebook outputs understandable and reproducible.
